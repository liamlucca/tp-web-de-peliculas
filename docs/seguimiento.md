# Task and Issue Tracking

## 1. Overview

This document records the tasks involved in the development of CineWeb, the distribution of responsibilities among team members, and the issues identified during implementation.

Task coordination was carried out through WhatsApp, while GitHub repositories were used to manage and track code changes.

## 2. Task Distribution and Collaboration

The development of CineWeb followed a collaborative approach. All team members contributed to different aspects of the project, including frontend development, backend development, testing, and problem-solving.

Tasks were distributed and coordinated through WhatsApp according to the project's needs and the progress of development. Responsibilities were flexible, and team members collaborated on different components rather than being restricted to specific roles.

GitHub was used to manage code changes and collaborate through branches and pull requests.

## 3. Issues and Improvements

During development, the team worked together to configure the local environment, implement the required functionality, and address technical issues.

Team members collaborated to identify problems, discuss possible solutions, and improve the integration between the frontend and backend.

Any outstanding issues should be documented here, including a brief description of the problem, its current status, and the steps taken to resolve it.
