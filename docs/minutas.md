## 2. Communication and Coordination

The team coordinated the development of CineWeb through WhatsApp messages rather than formal meetings.

Tasks were distributed among team members according to the project's requirements and the responsibilities associated with each part of the application. The team used WhatsApp to communicate progress, coordinate development activities, and discuss issues that arose during implementation.

## 3. Task Distribution

The project is organized into three separate repositories:

- **Frontend:** Development of the user interface and client-side functionality using React, TypeScript, and Vite.
- **Backend:** Development of the server-side functionality, API, and database integration using Node.js, Express, TypeScript, MikroORM, and MySQL.
- **Documentation:** A separate repository used to organize and maintain the project's documentation.

Team members coordinated their work through WhatsApp and used GitHub to manage code changes and collaborate on development.

## 4. Development Progress

Development focused on the frontend and backend components, with tasks distributed among team members.

The team worked on setting up the development environment, implementing the required functionality, and coordinating the integration between the frontend and backend.

The documentation repository was used to organize the project's documentation, including installation instructions, project information, and development records.
